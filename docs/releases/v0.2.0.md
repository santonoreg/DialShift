# DialShift v0.2.0 — Windows + Mac

DialShift now has ready-to-run downloads for Windows x64 and Apple Silicon Macs.
Both include .NET. Windows bundles VLC; Mac uses the built-in macOS audio player.

## Downloads

- **Windows 10/11, x64:** `DialShift-0.2.0-win-x64.zip`. Extract the entire ZIP and run `DialShift.exe`.
- **Apple Silicon, macOS 14+:** `DialShift-0.2.0-osx-arm64.zip`. Unzip and move `DialShift.app` to Applications.
- `SHA256SUMS.txt` contains checksums for both ZIPs.

The Mac app is ad-hoc signed, not Apple-notarized. If blocked after opening it,
use **System Settings → Privacy & Security → Open Anyway** for DialShift.
Intel Macs and Windows ARM do not have release downloads yet.

## What's new

- Mac menu-bar app with stations, weekly schedules, playback and volume controls.
- Native macOS audio, retry/fallback, schedule catch-up and optional launch at login.
- Import/export of stations and schedules on Mac, including Windows settings files.
- Fixed the Mac crash after station/schedule edits by updating the existing native menu.
- Added editor validation, persistence and menu-refresh regression checks.
- README now links directly to both platform downloads.

The Windows app keeps its existing WPF interface and behavior. Both builds include
only the three SomaFM starter stations: Groove Salad, Drone Zone and Secret Agent.

## Updating

Quit DialShift from its tray/menu-bar menu, then replace the old app files.
Stations and schedules are stored separately and remain intact.

To move stations from Windows to Mac, copy `%LOCALAPPDATA%\DialShift\settings.json`
and use **Settings → Import stations & schedule…** in the Mac app.

## Validation and known limits

Core/controller checks, Windows playback/UI checks and Mac package integrity checks
pass. Playback and station/schedule editing were manually confirmed on Apple Silicon
running macOS 15.7.3. Hardware Mac sleep/wake and login need broader testing.
Some Mac cosmetic issues remain, and track-title metadata is not available on Mac.
